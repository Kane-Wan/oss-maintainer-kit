# Code of Conduct

We want this project to be a respectful, practical place for maintainers and contributors.

Participants must:

- discuss ideas and code without personal attacks;
- assume good faith while remaining clear about technical risk;
- respect privacy and never publish another person's credentials or private data;
- avoid harassment, discrimination, threats, and deliberately disruptive behavior;
- accept maintainer decisions about project scope and safety.

Unacceptable behavior may be edited, removed, or result in temporary or permanent exclusion from project spaces. To report a conduct concern privately, contact the maintainer through the security reporting channel described in `SECURITY.md`. Reports will be reviewed as promptly and confidentially as practical.
