# Adopters

Repo Steward AI publishes only opt-in, verifiable adoption evidence.

## Public adopters

No external repository has opted in to this list yet. This is an honest early-preview status,
not an invitation to create artificial installations, downloads, or stars.

## Add a repository

Open a pull request that adds one row to the table below. The pull request must come from a
maintainer of the listed repository or link to their explicit approval.

| Repository                           | Workflow or usage evidence | Mode | Since | Maintainer approval |
| ------------------------------------ | -------------------------- | ---- | ----- | ------------------- |
| _Waiting for the first opt-in pilot_ | -                          | -    | -     | -                   |

Eligible evidence includes a public workflow file, a pull request using generated advice, or a
public issue describing the pilot. A GitHub star alone is not adoption evidence.

Use the [pilot report issue form](.github/ISSUE_TEMPLATE/pilot-report.yml) or the
[pilot report template](docs/PILOT_REPORT_TEMPLATE.md) to share results without exposing secrets
or private repository content.
